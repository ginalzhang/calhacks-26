# Phase 03 operator checklist

Prepared app: `/private/tmp/steady-phase03-20261024-01/Steady.app` (quit earlier Steady builds, then launch normally). Voice is disabled. Tests never enable real desktop input. Use disposable Krita 5.3.4 documents and report results in one batch; no observer/control session is needed.

1. **Prepare:** In Settings select camera/mode and built-in display. Start capture and use the existing per-camera calibration or complete five captures. Enable real input only after checking the disposable-document confirmation. If Accessibility is missing, grant it to this packaged app in System Settings, then Recover native helper. Configure convenient global bindings for Resume, Click and Set canvas; F8 toggles pen/marks corners, F9 pauses (Fn may be needed). Conflicts must remain visible. Close Settings and switch to Krita.
2. **Canvas and drawing:** Use the nonactivating panel’s Set canvas (or its configured key). Hover top-left + F8, then bottom-right + F8. Check reversed/small/outside/panel-overlap corners reject. Valid capture ends PAUSED. Resume after at least 500ms stable tracking; F8 down/up draws one explicit stroke. Click should act once. Cross the canvas edge while drawing: it must release; returning must stay pen-up. Pause before text entry or dialogs; the app does not inspect Krita dialogs.
3. **Krita effects and panel:** Verify actual document effects for Undo (Command-Z), Redo (Command-Shift-Z), Brush (B), Erase toggle (E), Bigger (]), Smaller ([). Report each effect, including failures. During a stroke move onto the panel: it must release. A configured Click over a button must invoke that control locally; panel background must do nothing, without clicking Krita beneath it. Check physical panel clicks preserve Krita focus. Collapse/expand, fullscreen and Spaces must preserve capture/panel visibility; explicit Resume may be required after panel geometry changes.
4. **Recovery/safety:** During a stroke, F9 must release immediately. Cover/turn away from camera; pointer freezes during short gaps and input pauses/releases by the 300ms maximum. Recovery must never resume or lower the pen; Palm also needs explicit selected-hand confirmation. Switch to another app/settings and back: input releases and stays paused until Resume. Check sleep/wake, camera disconnect, display geometry change and explicit Recover; canvas must be reconfirmed where prompted. Relaunch starts paused, camera/mic off, and requires canvas reconfirmation.
5. **Display/mode matrix:** Repeat the drawing/canvas/panel/recovery checks in Head and raised-hand Palm (record exact camera and posture). Select the external display separately in a negative-origin arrangement; verify all corner/pointer positions in logical points, including Retina/mixed-scale mapping, without a backing-scale offset. Changing display must invalidate canvas. Relaxed desk-facing Palm remains deferred to Phase 05.

**Batch report:** operator name/role; Mac/OS; camera + mode/posture; display origin/scale + window/fullscreen/Spaces; items passed/failed/not tried; actual shortcut/document effects; any accidental stroke or focus theft. Native timing diagnostics are sanitized under `~/Library/Application Support/Steady/phase03-evidence/`; do not send raw camera images. A visual impression alone does not establish a numeric release time. Missing hardware or measurements remain unverified, and Phase 03 stays blocked until mandatory evidence is accepted. Do not start Phase 04.
